US Accident Severity Prediction Using PySpark

Machine learning pipeline · Distributed data processing

Overview

Developed a machine learning pipeline using PySpark to analyze and predict traffic accident severity from a large-scale U.S. accident dataset. The project combined distributed data processing, feature engineering, model tuning, and statistical analysis to identify the factors that contribute most to roadway accident severity.

Problem

Traffic accidents are influenced by a variety of environmental, roadway, and weather-related factors. The goal of this project was to determine which factors have the strongest relationship with accident severity and evaluate how accurately machine learning models can predict severity using those variables.

My Role

Designed and implemented the entire analytics workflow, including:

  • Data ingestion using PySpark
  • Data cleaning and preprocessing
  • Feature engineering
  • Decision Tree model development
  • Hyperparameter tuning with cross-validation
  • Feature importance analysis
  • Data visualization and performance evaluation

Technologies

PySpark Python Pandas Matplotlib Seaborn Google Colab Machine Learning

Process

Data Engineering

  • Loaded and processed a large U.S. accident dataset using PySpark.
  • Cleaned inconsistent ZIP code formats.
  • Converted categorical and Boolean features into machine learning compatible formats.
  • Removed non-essential columns and handled missing data.
  • Prepared 20+ roadway, geographic, and weather variables for modeling.

Machine Learning Pipeline

Built a regression model to predict accident severity using factors such as:

  • Visibility
  • Temperature
  • Precipitation
  • Road features
  • Traffic control devices
  • Geographic location
  • Crash distance

The dataset was split into training and testing sets and trained using a Decision Tree Regressor.

Model Optimization

Improved model performance through:

  • Hyperparameter tuning
  • Grid search optimization
  • 3-fold cross-validation

Parameters evaluated included maximum tree depth and minimum instances per node.

Exploratory Analysis

Tested several hypotheses regarding weather conditions, road infrastructure, and traffic controls. Created specialized models that isolated weather-only predictors and road feature-only predictors. This provided additional insight into how different categories of variables influence accident severity.

Key Findings

  • Geographic and distance-related features were significantly stronger predictors than expected.
  • Many weather variables had less impact on severity than originally hypothesized.
  • Separate weather-only and roadway-only models helped isolate the contribution of specific feature groups.
  • Feature importance analysis revealed which variables most strongly influenced model predictions.

Visualizations

Produced multiple analytical visualizations, including:

  • Feature importance rankings
  • Correlation heatmaps
  • Predicted vs. actual severity scatterplots
  • Residual analysis plots
  • Error distribution histograms
