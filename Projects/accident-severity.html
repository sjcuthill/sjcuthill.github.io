The Problem

Why did this project need to exist?

Traffic severity is shaped by weather, roadway design, geography, and more—but raw accident data doesn’t explain itself. The question was which factors matter, how well a model can predict severity, and how to show that clearly in graphs.

02
The Approach

How did I approach it?

I structured the work as three acts: transform the dataset in Python until it was model-ready, train and tune a Decision Tree pipeline, then invest heavily in visualizations that made findings readable.

  • Clean and encode at scale with PySpark before modeling
  • Test weather-only and roadway-only models to isolate feature groups
  • Treat graphs as the primary insight layer—not an appendix
03
The Build

What did I actually create?

Dataset transformation. Loaded a large U.S. accident dataset; cleaned ZIP formats and missing values; converted categorical/Boolean fields; engineered 20+ roadway, geographic, and weather variables.

Machine learning. Decision Tree Regressor with train/test split, grid search, and 3-fold cross-validation on tree depth and minimum instances per node.

Graphs. Feature importance rankings, correlation heatmaps, predicted vs. actual scatterplots, residual plots, and error distribution histograms—the visuals that carried the story.

04
The Result

What came out of it?

  • Geographic and distance features were stronger predictors than expected.
  • Many weather variables mattered less for severity than hypothesized.
  • Separate feature-group models clarified what each category contributed.
  • Charts made model behavior interpretable for a non-tabular audience.
