New Leaf

Operations Dashboard

A landscaping business running on spreadsheets and verbal handoffs needed a connected system—secure data, reliable APIs, and environments you can trust while you ship.

Live truck tracker · Dispatch day lists · Crew assignment

01
The Problem

Why did this project need to exist?

Operations lived in manual processes—scattered updates, fragile handoffs, and no single place that reflected the real state of jobs, crews, and equipment.

Without a shared system, the business couldn’t scale how it scheduled work or trusted that everyone was looking at the same information.

02
The Approach

How did I approach it?

I treated the database and environments as first-class product work—not afterthoughts. That meant designing for row-level security from the start, planning migrations so schemas stayed consistent, and separating sandboxes and testing from anything production-like.

  • Map business workflows before tables, so the schema matched how the company actually runs.
  • Design API connections around the systems that already owned key data.
  • Use RLS so access rules travel with the data, not only the UI.
  • Keep sandboxes and test environments close enough to reality that migrations and edge cases show up early.
03
The Build

What did I actually create?

A live operations platform for New Leaf Landscape—dispatch, crew day lists, work records, and a truck tracker that refreshes in the field.

  • Live truck tracker with map positions refreshing every 30 seconds
  • Dispatch boards for unassigned work and per-crew day lists (route order, send to crew, roll unfinished)
  • Work records with invoice status and QuickBooks line-item mapping
  • API connections, schema migrations, and row-level security across environments
  • Business-specific workflows when a generic tool wouldn’t fit how the company runs
04
The Result

What came out of it?

A foundation the business can operate on: consistent data across environments, secured access at the database layer, and room to ship features without guessing whether testing matches reality.

The quieter win is operational trust—people and systems looking at the same state of jobs, crews, and resources.
